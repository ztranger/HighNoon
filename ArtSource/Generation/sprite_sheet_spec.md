# Спецификация набора спрайтшитов персонажа

Эталон поз и исходных размеров смерти: `G:/Projects/HighNoon/ArtSource/cowboy_death_sheet.png`.

Основной эталон масштаба художественного пикселя: **`G:/Projects/HighNoon/ArtSource/01_cowboy_base.png`**, исходный кадр **96 × 96 px**. Сравнивать с результатом в исходном размере 96 × 96 px. `GunslingerIdle.png` — дополнительный ориентир выразительности контура; его фон и размеры не переносить.

Назначение: создать **четыре отдельных спрайтшита для одного и того же персонажа**: idle (ожидание), ходьба, выстрел и смерть. Во всём наборе сохранять единые внешность, пропорции, экипировку, палитру, масштаб и характер отрисовки.

## Обязательный состав набора и направление

| Анимация | Обязательное имя файла | Требования |
|---|---|---|
| Idle / ожидание | `CharacterName_Idle.png` | Спокойная стойка с небольшим движением дыхания; плавный замкнутый цикл. |
| Ходьба | `CharacterName_Walk.png` | Полный цикл шага на месте для движения вправо; плавный переход от последнего кадра к первому. |
| Выстрел | `CharacterName_Shoot.png` | Оружие направлено вправо: подготовка, выстрел с обязательной вспышкой у дула, отдача и возврат в исходную позу. |
| Смерть | `CharacterName_Death.png` | Однократное падение с удержанием финальной позы; стадии по разделу 4. |

**Персонаж всегда ориентирован вправо во всех четырёх анимациях и во всех кадрах.** Не создавать варианты с ориентацией влево, развороты на противоположную сторону или зеркальное чередование кадров. Наклоны и падение не меняют выбранную сторону изображения персонажа; положение головы слева от ног в лежачей позе эталона не является указанием развернуть персонажа влево.

Каждая анимация — отдельный PNG **384 × 192 px**, содержащий **8 кадров по 96 × 96 px** в двух рядах по четыре кадра. Анимационный набор — **4 PNG-файла, всего 32 кадра**. Дополнительно обязательно сохранить **один отдельный кадр персонажа в профиль**; полный комплект — **5 PNG-файлов**. Не объединять четыре анимации в один общий лист.

Общие требования к формату, стилю, масштабу и опорной линии действуют для всех четырёх листов. Таблица пересчитанных габаритов и последовательность падения относятся **только к смерти**: не переносить уменьшение высоты и лежачие позы в idle, ходьбу или выстрел. Для этих трёх анимаций сохранять масштаб стоящего персонажа и допускать естественные изменения силуэта при дыхании, шагах и работе с оружием.

Рисовать и экспортировать кадры непосредственно в **96 × 96 px**, без увеличения. Один художественный пиксель равен одному пикселю PNG. Лист содержит 4 столбца × 2 строки и имеет размер **384 × 192 px**. Высота персонажа в стойке — около **80 px**. Масштабирование выполняет пользователь в движке; при экспорте масштаб не применять. Размеры и границы смерти ниже соответствуют исходному эталону. Рекомендации по pivot и времени кадров не являются метаданными исходного PNG.

## Имена файлов и папка персонажа

Все имена файлов и папок задаются на английском языке. Обязательный шаблон имени файла спрайтшита: **`CharacterName_AnimationName.png`**, где:

- `CharacterName` — имя или название персонажа на английском языке, одинаковое для всех пяти файлов и папки.
- `AnimationName` — анимация, содержащаяся в спрайтшите: строго **`Idle`**, **`Walk`**, **`Shoot`** или **`Death`**, с указанным регистром.
- Имя персонажа и название анимации разделяются одним символом подчёркивания `_`; суффикс `_sheet` не добавляется.

Для каждого персонажа создать отдельную папку **`ArtSource/Characters/CharacterName`** относительно корня проекта HighNoon и поместить все четыре спрайтшита и отдельный кадр `CharacterName_Side.png` непосредственно в неё. В текущем проекте полный путь: **`G:/Projects/HighNoon/ArtSource/Characters/CharacterName`**. `CharacterName` — подставляемое имя, а не буквальное название папки. Например, для персонажа `Cowboy`:

```text
ArtSource/Characters/Cowboy/
    Cowboy_Idle.png
    Cowboy_Walk.png
    Cowboy_Shoot.png
    Cowboy_Death.png
    Cowboy_Side.png
```

## Отдельный кадр персонажа в профиль

Для каждого персонажа, помимо четырёх спрайтшитов, обязательно сохранять **`CharacterName_Side.png`** в той же папке `ArtSource/Characters/CharacterName`. Это одиночное изображение для просмотра персонажа целиком, без нарезки спрайтшита. Суффикс `Side` обозначает отдельный вид, а не пятую анимацию.

- Размер **96 × 96 px**, PNG RGBA, прозрачный фон с альфа-каналом только 0 или 255.
- Один персонаж в полный рост, **вид сбоку, лицом вправо**, в спокойной читаемой стойке с видимой экипировкой.
- Использовать первый нейтральный кадр Idle: сохранить его отдельным файлом без изменения масштаба, палитры, обводки и положения внутри ячейки. Первую позу Idle заранее строить как подходящий профильный вид.
- Высота персонажа около **80 px**, опорная точка **(48, 88)**, нижний занятый ряд **y = 87**, нижний отступ **8 px**. Сохранить весь квадрат кадра без автоматической обрезки.
- Без дополнительных ракурсов, повторов персонажа, подписей, рамок, декоративного фона и свечения.

## 1. Технический формат

| Параметр | Значение |
|---|---|
| Размер изображения | **384 × 192 px** |
| Формат | PNG, RGBA |
| Сетка | **4 столбца × 2 строки** |
| Размер кадра | **96 × 96 px** |
| Количество кадров | 8 |
| Порядок кадров | Слева направо: кадры 1–4 в верхнем ряду, 5–8 в нижнем |
| Промежутки между ячейками | 0 px |
| Внешние поля сетки | 0 px |
| Фон | Полностью прозрачный |
| Альфа-канал | Только 0 и 255; полупрозрачных пикселей нет |
| Нижний занятый ряд | **y = 87** локально внутри каждого кадра |

Чёрный фон в некоторых просмотрщиках не является заливкой изображения.

Обязательная раскладка кадров для каждой анимации:

```text
1  2  3  4
5  6  7  8
```

Кадр с индексом `i` (от 0 до 7) вырезается следующим образом (`%` — остаток от деления, `floor` — округление вниз):

```text
x = (i % 4) * 96
y = floor(i / 4) * 96
width = 96
height = 96
```

## 3. Художественный стиль

- Пиксель-арт с отчётливо видимой крупной пиксельной структурой, выразительным тёмным контуром и чёткими цветовыми пятнами, как у ковбоя в `GunslingerIdle.png`, для игры с видом сбоку. Персонаж преимущественно показан в профиль с небольшим разворотом корпуса.
- Умеренно реалистичные пропорции: вытянутое тело, различимые суставы и конечности, без выраженной карикатурности.
- Тёмный контур толщиной около 1 px; местами утолщается в тенях и пересечениях форм.
- Ступенчатые пиксельные края без сглаживания прозрачностью, размытия и мягкого внешнего ореола.
- Объём передаётся цветовыми пятнами света, полутона и глубоких теней на коже, ткани и аксессуарах.
- Мелкие детали подчинены читаемости силуэта при исходном размере.
- Палитра эталона приглушённая и преимущественно тёплая: коричневая шляпа и обувь, кремовая рубашка, тёмный жилет, синие брюки, красный шейный платок.
- Нет окружения, частиц, крови, подписей или отдельной падающей тени. Обязательное исключение для Shoot — вспышка выстрела у дула, описанная ниже.

### Отрисовка в исходном разрешении

`01_cowboy_base.png` — кадр 96 × 96 px, видимый персонаж 31 × 80 px. Ориентироваться на его плотность деталей. Результат `CabaretSinger5_Side.png` имеет избыточно мелкую фактуру волос, чулок, лица и оружия; не использовать его как эталон пикселизации.

1. Отрисовать кадр непосредственно в 96 × 96 px: стойка около 80 px высотой, нижний занятый ряд y = 87, pivot (48, 88), нижний отступ 8 px.
2. Упростить детали: волосы — крупные пряди, ткань — несколько цветовых пятен; сетку чулок, кружево и украшения передавать редкими читаемыми группами пикселей. Контур — обычно 1 px, локально толще.
3. Сохранить кадры в исходном разрешении, без увеличения, сглаживания, интерполяции и повышения резкости.
4. Собрать восемь кадров в лист 384 × 192 px, 4 столбца × 2 ряда. Side экспортировать из первого кадра Idle как отдельный PNG 96 × 96 px.
5. Проверить читаемость лица, силуэта и экипировки при масштабе 1:1 и соответствие эталону. Простое уменьшение детальной иллюстрации без упрощения форм недостаточно.

### Пиксельная структура и обводка: обязательное соответствие ковбою

В сравнении с `GunslingerIdle.png` результат `CabaretSinger3_Idle.png` выглядит более сглаженным и мелкодетализированным: пиксельные ступени и тёмная обводка выражены слабее. Для новых персонажей ориентироваться на **отчётливую пиксельную структуру ковбоя**. Певица служит примером нежелательного отклонения в манере отрисовки, а не эталоном стиля. Сравнивать персонажей при одинаковой высоте на экране, поскольку масштаб превью влияет на видимость пикселей.

- **Нативная пиксельная сетка 96 × 96.** Один художественный пиксель — один пиксель итогового PNG. Все детали и прозрачность строятся на этой сетке, без субпиксельного сглаживания. Однопиксельные детали допустимы; обязательных блоков 4 × 4 нет. Экспортировать без масштабирования.
- **Выразительная тёмная обводка.** Почти чёрный или очень тёмный цвет по внешнему силуэту, обычная толщина около **1 px** в конечном кадре. Контур должен уверенно отделять персонажа от фона; в местах перекрытия руки, корпуса, одежды и оружия использовать тёмные внутренние разделители. Не делать контур тонким, размытым или теряющимся в заливке.
- **Жёсткие границы света и тени.** Объём передавать компактными цветовыми пятнами с заметной разницей тона, а не плавными градиентами. Для основного материала ориентироваться на несколько ясно различимых тонов (например, базовый, свет, тень, глубокая тень); это художественный ориентир, не ограничение общего числа RGB-цветов.
- **Детали через пиксельные группы.** Черты лица, пряди, складки и украшения должны читаться как компактные угловатые формы. Избегать множества тонких линий и мелкого цветового шума, создающих впечатление уменьшенной цифровой иллюстрации.
- **Без смягчения рисунка.** Не применять сглаживание цветовых границ или прозрачности, размытие, мягкую кисть, живописную растушёвку, свечение и реалистичные плавные переходы. Простое увеличение мягко нарисованного персонажа не обеспечивает нужного стиля.
- **Единство всех файлов.** Одинаковая крупность пикселей, контраст, толщина обводки и способ изображения материалов обязательны для Idle, Walk, Shoot, Death и Side. Фон и световой ореол из изображения ковбоя в экспорт не включать.

В исходном файле **6682 уникальных RGB-цвета среди непрозрачных пикселей**. Не трактовать эталон как строго 16- или 32-цветную графику. Для повторения важнее характер контура, тональный контраст и плотность деталей. Цвета одежды другого персонажа могут отличаться.

### Обязательная вспышка выстрела в Shoot

- В момент выстрела обязательно показать **вспышку у среза ствола** в одном или двух последовательных кадрах анимации `CharacterName_Shoot.png`.
- Вспышка начинается непосредственно у дула, направлена вправо по оси ствола и согласована с моментом выстрела и началом отдачи. В подготовительных кадрах и после выстрела она отсутствует.
- Рисовать её в том же пиксельном стиле: компактная угловатая форма, чёткие пиксельные края, светлое жёлтое или кремовое ядро и оранжевые внешние участки. Без размытия, мягкого свечения и полупрозрачного ореола; альфа только 0 или 255.
- Вспышка целиком помещается в ячейку 96 × 96 px, не обрезается и не попадает в соседний кадр. Предусмотреть для неё место при постановке оружия, сохраняя масштаб персонажа.
- Вспышка является частью кадров Shoot; отдельный файл для неё не требуется. В Idle, Walk, Death и Side вспышки нет.

## 4. Постановка анимации смерти

Общее движение: **отклонение назад → оседание → падение вперёд → лежачая поза**.

| Кадр | Поза и функция |
|---|---|
| 1 | Вертикальная исходная стойка. Персонаж смотрит вправо, оружие опущено. |
| 2 | Реакция на поражение: голова и корпус отклоняются назад, колени сгибаются. |
| 3 | Персонаж оседает, корпус наклоняется вперёд, голова опускается. |
| 4 | Падение на колено. Рука и оружие приближаются к земле. |
| 5 | Персонаж заваливается вниз, опираясь рукой; корпус становится почти горизонтальным. |
| 6 | Корпус продолжает опускаться, ноги вытягиваются вправо. |
| 7 | Персонаж лежит: голова слева, ноги справа. Силуэт низкий и вытянутый. |
| 8 | Финальное положение с небольшими изменениями рисунка. Габариты совпадают с кадром 7, но изображения не идентичны. |

PNG не содержит длительности кадров. Для первого просмотра рекомендуется **100–125 мс на кадр** (8–10 кадров/с), без зацикливания, с удержанием последнего кадра. Это отправная точка для настройки, а не измеренное свойство эталона.

## 5. Требования к четырём спрайтшитам одного персонажа

1. Для каждого из четырёх спрайтшитов использовать холст **384 × 192 px**, сетку **4 × 2**, ячейку **96 × 96 px**.
2. В первой позе выдержать общую высоту около **80 px**, включая головной убор; ориентир для верхнего и нижнего отступов — по **8 px**.
3. В локальных координатах каждого кадра удерживать нижний занятый ряд на **y = 87**, а центр силуэта — около **x = 48**.
4. В спрайтшите смерти повторить стадии падения и приблизительные габариты силуэтов из таблицы. Точные боковые отступы могут отличаться из-за телосложения и экипировки; значения таблицы описывают исходные габариты эталона, а не обязательную форму другого персонажа.
5. Сохранять узнаваемые черты нового персонажа во всех позах: одежду, причёску, аксессуары, оружие и их расположение. Экипировку эталона переносить только если она соответствует заданию на нового персонажа.
6. Не обрезать выступающие детали краями ячейки. Для смерти ориентироваться на диапазон эталона; для других анимаций боковые границы могут отличаться, например при вытянутом оружии. Диапазон в исходном масштабе: **x = 15–80, y = 8–87**.
7. Сохранять единый масштаб тела и деталей между кадрами и всеми четырьмя спрайтшитами. Уменьшение высоты силуэта должно быть следствием изменения позы, а не масштабирования изображения.
8. Экспортировать PNG RGBA с полностью прозрачным фоном и без полупрозрачного ореола.
9. Сохранить все ячейки целиком, без автоматической обрезки, поворота и плотной упаковки кадров.
10. Экспортировать без масштабирования. Масштаб задаёт пользователь в движке; для чётких пикселей использовать Nearest / Point, желательно целочисленное увеличение.
